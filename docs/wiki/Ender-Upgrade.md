# Ender Upgrade

Links a DeepNull or DampNull to a docked Null of the same type and tier, then mirrors that docked storage across dimensions.

## Availability

- DeepNull or DampNull
- Every tier

## How To Use

1. Shift-right-click a docked Null with the Ender Upgrade to link it.
2. Install the linked upgrade into another Null of the same type and tier.
3. The installed Null mirrors the docked source until the source Null is removed or the Docking Station is broken.
