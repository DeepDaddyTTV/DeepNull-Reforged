# Stone Generator

The Stone Generator keeps selected stone materials stocked inside a DampNull without consuming its stored lava or water.

## Availability

- DampNull only
- Every tier

## Selectable Outputs

- Cobblestone
- Diorite
- Andesite
- Granite
- Cobbled Deepslate
- Tuff

## Tier Differences

| Tier | Rate |
| --- | ---: |
| Redstone | 1/s |
| Lapis | 2/s |
| Iron | 3/s |
| Gold | 4/s |
| Diamond | 5/s |
| Emerald | 10/s |
| Creative | 10/s |

## Notes

- Requires both water and lava to be present in the DampNull
- Uses the hidden dock buffer when the DampNull is docked
