# Stoneworks Upgrade

Stoneworks keeps processed stone materials stocked by converting stored cobblestone down a round-robin chain.

## Availability

- DeepNull only
- Every tier

## Monitored Outputs

- Dirt
- Gravel
- Sand
- Dust, if a matching recipe exists in the pack
- Clay, when a carried DampNull has water
- Glass, when Auto-Smelting is also installed

## Notes

- Uses the `Stoneworks Amount` monitor value
- Monitored outputs stop processing once they hit the configured target amount
- Middle-click can set custom extraction minimums for stored items
