# Energy Upgrade

Adds FE storage and transfer to DeepNulls.

## Availability

- DeepNull only
- Diamond tier and above

## Tier Differences

| Tier | Capacity | Transfer |
| --- | ---: | ---: |
| Diamond | 100,000 FE | 2,000 FE/t |
| Emerald | 1,000,000 FE | 20,000 FE/t |
| Creative | Infinite-style behavior | Infinite-style behavior |
