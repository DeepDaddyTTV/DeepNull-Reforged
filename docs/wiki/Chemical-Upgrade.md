# Chemical Upgrade

Adds Mekanism chemical support to DampNulls when Mekanism is installed.

## Availability

- DampNull only
- Every tier

## Notes

- Transfer only: no world placement or pickup
- One chemical per tank slot
- Shift-right-click compatible chemical handlers to fill and drain
- Respects the global chemical-storage config toggle

## Crafting

See JEI or GuideME for the current recipe.
