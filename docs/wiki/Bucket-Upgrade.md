# Bucket Upgrade

The Bucket Upgrade lets DeepNulls use stored buckets and compatible fluid containers directly from item slots.

## Availability

- DeepNull only
- Every tier

## Notes

- Needed for Null Workbench DeepNull-to-DampNull conversions
- Enables direct use of stored buckets instead of only storing them
