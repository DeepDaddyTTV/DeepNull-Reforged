# Sponge Upgrade

The Sponge Upgrade lets a DampNull absorb multiple visible source blocks at once.

## Availability

- DampNull only
- Every tier

## Tier Differences

| Tier | Max Sources | Range |
| --- | ---: | --- |
| Redstone | 8 | 6x6x4 |
| Lapis | 10 | 8x8x6 |
| Iron | 12 | 8x8x6 |
| Gold | 16 | 10x10x8 |
| Diamond | 32 | 12x12x10 |
| Emerald | 32 | 12x12x10 |
| Creative | 32 | 12x12x10 |

## Notes

- Absorbs visible source blocks around the clicked source block
- Only stores fluids that fit into matching or empty DampNull tanks
