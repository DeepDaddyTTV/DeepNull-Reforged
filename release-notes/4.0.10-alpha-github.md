# DeepNull Reforged 4.0.10-alpha

This is the first public **alpha Fabric build** for **Minecraft 1.21.1**.

This build is not final. Expect bugs, parity gaps, and edge cases that still need cleanup before a stable Fabric release.

## Included in this alpha

- Ported the mod bootstrap and build pipeline from NeoForge to Fabric for Minecraft 1.21.1
- Added Fabric-side registration for the core mod content, menus, recipes, and client setup
- Restored DeepNull and DampNull custom item rendering
- Restored Shift + scroll slot selection
- Fixed compact GUI stack counts so large values display correctly again, such as `1K`
- Fixed creative DeepNull energy syncing and display behavior
- Fixed DampNull fluid placement on Fabric
- Fixed creative DampNull fluid absorption so matching source fluids stay in the selected tank and overflow is voided instead of spilling into another tank

## Alpha warning

- This is an **alpha Fabric build**
- Expect bugs
- Back up worlds before testing
- Report issues with exact reproduction steps when possible

## Target

- Minecraft `1.21.1`
- Loader `Fabric`
- Release asset: `deepnull-reforged-4.0.10-alpha-fabric.jar`
