# DeepNull Reforged `4.2.0-beta-fabric`

Fabric beta for **Minecraft 1.21.1**.

This update brings the Fabric branch up through the current **4.2.0** `1.21.1` feature set.

This is still a **beta** build of the Fabric port. It is playable, but it is not final yet. Expect bugs, edge cases, and remaining mod-compat gaps while the port continues to be stabilized.

## What's New

- Fabric `1.21.1` is now brought up to the current `4.2.0` feature set from the main `1.21.1` branch
- Added a global auto-pickup toggle with a keybind and saved per-player state
- Added the new `Connections` filter preset for common cables, pipes, ducts, conduits, buses, tunnels, and similar transport parts
- DampNull default fluid capacities are now doubled for the current balance target
- Existing configs with the old default fluid capacities are migrated automatically to the new defaults
- Docked DampNulls can now transfer supported fluid containers directly with right click
- Gas-upgraded DampNulls now correctly reject normal fluid insertion
- Dock automation extraction now matches the current `1.21.1` behavior more closely, including keep-one and custom minimum handling
- Stored right click item-use proxying now works for more supported items and is no longer limited to singleton stacks
- Added a config gate for Crafting Tweaks return integration
- JEI dry-run transfer feedback is improved when ingredients are missing
