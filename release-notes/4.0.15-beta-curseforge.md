Beta Fabric port for Minecraft 1.21.1.

This build is still not final. Expect bugs, parity gaps, and edge cases while the Fabric port is still being stabilized.

What is working in this build:

- Fabric 1.21.1 port of DeepNull Reforged
- Restored DeepNull and DampNull custom item rendering
- Shift + scroll slot selection works again
- Middle click is blocked only inside the DeepNull GUI where custom extraction uses it
- Stored right click item-use proxy behavior works again for singleton items inside the DeepNull
- Compact GUI count formatting works again, including values like `1K`
- Creative DeepNull energy display is fixed
- DampNull fluid placement is fixed
- Creative DampNull now absorbs matching source fluids into the selected tank and voids overflow instead of moving it into another tank
- DeepNull and DampNull GUI titles are restored
- Custom extraction state cleanup and zero-value handling now match the 4.0.15 hotfix behavior

Please back up worlds before testing and report bugs with exact steps when possible.
