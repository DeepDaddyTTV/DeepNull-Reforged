# DeepNull Reforged `4.1.3-beta-fabric`

Fabric beta for **Minecraft 1.21.1**.

This is a **beta** build of the Fabric port. It is playable, but it is not final yet. Expect bugs, edge cases, and a few remaining parity gaps while the port continues to be stabilized.

## Highlights

- DeepNull Reforged is available on **Fabric 1.21.1**
- Fabric config files load through a real Fabric-compatible config backend
- DeepNull and DampNull custom item rendering is restored
- `Shift + Scroll` slot selection works again
- Stored right click item-use behavior works again for supported singleton items inside the DeepNull
- GUI stack counts are formatted correctly again, including values like `1K`
- Creative DeepNull energy display is fixed
- DampNull fluid placement is fixed
- Creative DampNull keeps matching source fluids in the selected tank and voids overflow instead of moving it into another tank
- DeepNull auto-pickup absorbs and voids matching item overflow by default when the matching stored slot is already full
- Added the `voidFullItemsOnPickup` server config option for the new overflow behavior
- Chemical Upgrade now only loads and appears when Mekanism is installed and chemical storage is enabled
- Stoneworks dust recipes now fall back more reliably when a valid dust block item exists
- JEI carried-crafting transfer has been reworked again to better respect DeepNull extraction limits and restore leftovers back to the preferred DeepNull
- Crafting-grid return handling now survives menu changes more reliably by snapshotting the crafting contents client-side before return
- Crafting Tweaks clear-grid compatibility is included when Crafting Tweaks is installed

## Notes

- Middle click is blocked only inside the DeepNull GUI where custom extraction uses it
- Fabric now generates real `client`, `common`, and `server` config files for DeepNull Reforged
- This build should be considered **test-ready**, not final
- Back up worlds before updating

## Bug Reports

If you hit a problem, please report it with:

- The exact item, block, or screen involved
- What you expected to happen
- What actually happened
- Crash log or latest log if available
