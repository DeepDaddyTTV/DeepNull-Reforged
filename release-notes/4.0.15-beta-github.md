# DeepNull Reforged 4.0.15-beta-fabric

This is a public **beta Fabric build** for **Minecraft 1.21.1**.

This build is still not final. Expect bugs, parity gaps, and edge cases while the Fabric port continues to settle.

## Included in this beta

- Fabric 1.21.1 port of DeepNull Reforged
- Restored DeepNull and DampNull custom item rendering
- Restored Shift + scroll slot selection
- Fixed middle click behavior so pick block is blocked only inside the DeepNull GUI where custom extraction uses it
- Restored stored right click item-use proxy behavior for singleton items inside the DeepNull
- Fixed compact GUI stack counts so large values display correctly again, such as `1K`
- Fixed creative DeepNull energy syncing and display behavior
- Fixed DampNull fluid placement on Fabric
- Fixed creative DampNull fluid absorption so matching source fluids stay in the selected tank and overflow is voided instead of spilling into another tank
- Restored the DeepNull and DampNull info panel titles in the GUI
- Fixed custom extraction state cleanup and zero-value handling to match the 4.0.15 hotfix behavior

## Beta warning

- This is a **beta Fabric build**
- Expect bugs
- Back up worlds before testing
- Report issues with exact reproduction steps when possible

## Target

- Minecraft `1.21.1`
- Loader `Fabric`
- Release asset: `deepnull-reforged-4.0.15-beta-fabric.jar`
