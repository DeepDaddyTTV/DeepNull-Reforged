# Stone Generator

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="deepnullreforged:stone_generator_upgrade" />
</Column>

Generates a selected stone variant inside a DampNull while both water and lava are present. The fluids are required but not consumed.

## Availability

- DampNull only
- Every tier

## Stone Types

- Cobblestone
- Diorite
- Andesite
- Granite
- Cobbled Deepslate
- Tuff

## Tier Differences

| Tier | Rate |
| --- | ---: |
| Redstone | 1/s |
| Lapis | 2/s |
| Iron | 3/s |
| Gold | 4/s |
| Diamond | 5/s |
| Emerald | 10/s |
| Creative | 10/s |
