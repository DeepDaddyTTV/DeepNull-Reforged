# Bucket Upgrade

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="deepnullreforged:fluid_upgrade" />
</Column>

The Bucket Upgrade lets a DeepNull use stored buckets and compatible fluid containers directly from item slots.

## Availability

- DeepNull only
- Every tier

## Notes

- Separate from DampNull, which is dedicated tank storage
- Used by the Null Workbench to convert DeepNulls into DampNulls
