# Auto-Smelting Upgrade

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="deepnullreforged:auto_smelting_upgrade" />
</Column>

Automatically smelts supported world pickups when the raw or cooked result is already stored. It only applies to world pickup, not dock transfer or inventory transfer.

## Availability

- DeepNull only
- Every tier

## Notes

- Has its own whitelist / blacklist filter screen
- Ore blocks are intentionally excluded
